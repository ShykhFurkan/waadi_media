## 4. Mobile Round M1 — Before vs After Improvements

| Metric | Before Round M1 | After Round M1 | Status / Resolution |
| :--- | :---: | :---: | :--- |
| **Horizontal Overflow** | Found on multiple viewports (<390px, marquee bands, tables) | **0 across all 13 pages & 5 viewports** | Contained with `[contain:paint]`, `overflow-hidden`, and stacked mobile cards |
| **Interactive Tap Targets < 44px** | 120+ sub-44px targets found | **0 across all pages** | Enforced 44px min-h/min-w, 44px row checkboxes, 44px breadcrumbs/links |
| **Form Inputs < 16px Font** | 14px–15px on mobile inputs | **0 (All inputs >= 16px)** | Prevents iOS Safari auto-zoom |
| **Body Copy Minimum** | 14px–15px in places | **>= 17px body, 19px–20px lead** | Clamped typography with `text-wrap: balance` |
| **Combined Fixed UI Ratio** | Exceeded 21.1% on small viewports | **<= 19.3% of 568px, 17.1% of 640px** | Under the 20% limit on all mobile viewports |
| **Bottom Bar CTA Overlap** | Overlapped hero CTA on 320x568 | **0 Overlap** | Adjusted hero top padding and spacing |
| **Automated Playwright Mobile Suite** | None | **39 / 39 Tests Passing** | Pixel 5, iPhone 13 (WebKit), 320x568 |
| **First Load Mobile JS** | ~180KB | **172KB gzipped** | Under 190KB threshold |
| **CLS (Cumulative Layout Shift)** | 0.08 | **0.00** | Rock solid layout stability |
